# AMA Answers

### Adhikya Edammala — What is Least Privilege?
Least Privilege means giving only the minimum permissions needed to perform a task.

### Allanki VV Manikanta Sai — What is LLM?
LLM (Large Language Model) is an AI model trained on large amounts of text to understand and generate human-like responses.

### Boorle Sowmya Sri Lakshmi — What are Props?
Props are data passed from a parent component to a child component in React. They are read-only.

### Nayunipatruni Harsha Vardhan — What is `useState()`?
`useState()` is a React Hook used to create and manage state in functional components.

### Vikas Mehta — Difference between an Agent and LLM?
- **LLM:** Understands input and generates responses.
- **Agent:** Uses an LLM with tools, planning, and actions to complete tasks.

> **LLM = Brain | Agent = Brain + Tools + Actions**
