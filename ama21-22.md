# AMA 21 and 22 Questions & Short Answers

### Adhikya Edammala — What are the rules in Claude Code?

Claude Code follows project instructions defined in files like `CLAUDE.md`. These rules guide coding style, project conventions, tools, and how Claude should work within the project.

### Boorle Sowmya Sri Lakshmi — Difference between `package.json` and `package-lock.json`

* **`package.json`**: Defines project metadata, scripts, and dependency ranges.
* **`package-lock.json`**: Locks the exact dependency versions installed.

### Nayunipatruni Harsha Vardhan — Difference between Opus and Fable

* **Opus**: A Claude AI model designed for complex reasoning and coding tasks.
* **Fable**: A programming language/compiler ecosystem for functional programming, commonly targeting JavaScript and .NET.

### Rongala Vasu — What are the TCL commands?

Common TCL (Transaction Control Language) commands are:

* `COMMIT` — Saves a transaction.
* `ROLLBACK` — Undoes a transaction.
* `SAVEPOINT` — Creates a point to roll back to.

### Vikas Mehta — What is Event Delegation?

Event delegation is a JavaScript technique where a parent element handles events from its child elements using event bubbling.

Use **Context API**, state management libraries, or component composition to share data without passing props through many levels.

### Nayunipatruni Harsha Vardhan — What is `useMemo`?

`useMemo` is a React Hook that memoizes a calculated value so it is not unnecessarily recalculated on every render.

### Rongala Vasu — Why are Hooks important in React?

Hooks allow functional components to use **state, lifecycle features, and other React features** without using class components.
