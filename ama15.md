## Adhikya Edammala
**Question:** What is the Open/Close Principle?

**Answer:**
The **Open/Closed Principle (OCP)** is one of the SOLID principles of object-oriented design. It states that **software entities (classes, modules, functions) should be open for extension but closed for modification**. This means you should be able to add new functionality without changing existing code, reducing the risk of introducing bugs.

## Allanki VV Manikanta Sai
**Question:** What is RabbitMQ?

**Answer:**
**RabbitMQ** is an open-source **message broker** that enables different applications or services to communicate by sending and receiving messages through queues. It helps build scalable, reliable, and asynchronous systems by decoupling producers and consumers.

## Boorle Sowmya Sri Lakshmi
**Question:** What is the use of Docker Compose?

**Answer:**
**Docker Compose** is a tool used to define and manage **multi-container Docker applications** using a `docker-compose.yml` file. It allows you to start, stop, and configure multiple containers (such as a web server, database, and cache) with a single command like `docker compose up`.

## Nayunipatruni Harsha Vardhan
**Question:** What is Dynamic Typing?

**Answer:**
**Dynamic typing** is a feature where the **type of a variable is determined at runtime**, not when the code is written. In dynamically typed languages like Python, you don't need to explicitly declare variable types, and a variable can hold different types of values during execution.

Example:
```python
x = 10      # Integer
x = "Hello" # String
```

## Vikas Mehta
**Question:** What is the purpose of `manage.py`?

**Answer:**
`manage.py` is a command-line utility in **Django** that helps developers interact with their project. It is used to perform administrative tasks such as:
- Running the development server (`python manage.py runserver`)
- Creating database migrations (`python manage.py makemigrations`)
- Applying migrations (`python manage.py migrate`)
- Creating a superuser (`python manage.py createsuperuser`)
- Running tests and other management commands.
