# AI Q&A

## Adhikya Edammala

**Q:** What is model choice and reasoning?\
**A:** Model choice is selecting the AI model based on the task.
Reasoning is how deeply the model thinks before answering.

## Allanki VV Manikanta Sai

**Q:** What are different Claude models?\
**A:** Common Claude models include Claude Opus (best quality), Claude
Sonnet (balanced), and Claude Haiku (fastest).

## Arpit Yadav

**Q:** What is hallucination?\
**A:** Hallucination is when an AI generates incorrect or made-up
information as if it were true.

## Boorle Sowmya Sri Lakshmi

**Q:** What are 3 things a token is dependent on?\
**A:** Language, text length, and tokenizer/model used.

## Nayunipatruni Harsha Vardhan

**Q:** Does creating a new chat reset the context window?\
**A:** Yes. A new chat starts with a fresh context window.

## Parlapalli Sulochana

**Q:** Are model choice and reasoning mode the same?\
**A:** No. Model choice selects the AI model, while reasoning mode
controls how much reasoning the model uses.

## Rongala Vasu

**Q:** What do you mean by streaming response?\
**A:** Streaming sends the response token-by-token as it's generated
instead of waiting for the full answer.

## Vikas Mehta

**Q:** What makes a prompt good?\
**A:** A good prompt is clear, specific, provides context, and states
the desired output.

## Santu

**Q:** What is the benefit of using Claude SDK over hitting the API
directly?\
**A:** The SDK simplifies authentication, request handling, streaming,
retries, and error management, reducing boilerplate code.
